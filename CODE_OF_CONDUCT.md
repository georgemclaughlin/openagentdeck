# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is adopted here by reference and applies to all project spaces: issues, pull requests, discussions and review comments.

In short: be respectful, assume good faith, keep feedback about the work and not the person, and do not harass anyone.

## Reporting and enforcement

Report unacceptable behavior to the maintainer by opening a GitHub issue that does not repeat the offending content, or, for anything sensitive, by contacting the maintainer, Hector Zarate, through [his GitHub profile](https://github.com/HectorZarate). Reports are handled in confidence. The maintainer may remove comments, lock threads or block participants who violate this code, following the enforcement guidelines in the Covenant.
